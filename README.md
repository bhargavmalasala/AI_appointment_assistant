# Voice AI Doctor Appointment Assistant

A real-time voice-based doctor appointment
booking assistant built using Pipecat and React.

## Tech Stack

- React + Vite
- Python
- Pipecat
- ElevenLabs STT and TTS
- Google Gemini
- SQLite

## Project Structure

- frontend: React dashboard
- backend: Python voice pipeline

## Features

- Check doctor availability
- Book appointments
- Cancel appointments
- Live voice conversation
- Appointment dashboard
